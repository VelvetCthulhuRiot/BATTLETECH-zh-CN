## v1.2.4 — 任务进度百分比 / 又一个多余的 "S" / 部件制造商名全部译出

这一版**没有任何游戏行为或存档相关的改动**（两个模组仍是普通游戏模组 + `IsSaveAffecting: false`，
`BTHanHuaFont.dll` 与字形图集都没动），改的是**译文**：

### 1. 战斗界面任务目标的"完成百分比"显示不出来

界面在目标下面显示了一串字面文字 `[完成百分比]`，而不是数值。原因：`[percentageComplete]`
是一条**标记串** —— 游戏先把这段文字本地化，**再在结果里找这个 token 替换成真实百分比**。
我们把它译成中文之后游戏就找不到了，于是原样显示。官方德语/法语都**保留英文原文不译**，这就是证据。
已改回与官方完全一致的写法；同一个家族的 `[durationRemaining]`（"剩余时间"型目标）也一并修好。

### 2. 机甲库面板里又多出一个 "S"（显示成"0部件 S"）

和 v1.2.2 修过的"12吨S剩余"是同一个毛病：英文模板里的 `{1}` 是**复数后缀 "s"**，
中文照抄就会多出一个字母。这一轮按特征把全库扫了一遍，共修 5 条：

| 英文模板 | 旧显示 | 现在 |
|---|---|---|
| `{0} component{1}` | 0 部件 S | 0 部件 |
| `{0} day{1}` | 3 天 S | 3 天 |
| `-{0}/{1}day{2}…MechTech Rating` | -3 / 5 天 s | -3 / 5 天 |
| `Game starting in: {0} second{1}` | …5 秒 s | …5 秒 |
| `requires {0} more part{1}` | 还需要 2 个 s 部件 | 还需要 2 个部件 |

判据一律是官方 de/fr —— 例如德语直接硬写 `{0} KOMPONENTE(N)`，根本不接 `{1}`。

### 3. 部件制造商名全部译出（57 个厂商）

机甲库与商店里每个武器/设备条目上那行小字是**厂商名**，此前有一批从来没译过，
所以在简体中文里直接显示英文（`GM`、`HELLION`、`SPERRY BROWNING`、`KRUPP`、`HOLLY`…）。
这一版从游戏数据里抽全 **57 个**厂商，按三种策略统一处理：

- **音译**（地名/人名/品牌）：`Krupp→克虏伯`、`Sperry Browning→斯佩里·勃朗宁`、
  `Kallon→卡隆`、`TharHes→塔尔赫斯`、`Mydron→迈德隆`…
- **意译**（有明确含义的词）：`Hellion→狱火工业`、`ExoStar→异星工业`、`Defiance→挑战者工业`、
  `StarCorps→星团工业`、`Skylight→曙光科技`、`Valiant→英勇工业`…
- **特殊**：`Kali Yama→迦梨·夜摩`、`Kong Interstellar→金刚星际`、`Magna VI→玛格纳 VI`、`Raker IV→雷克 IV`

纯缩写厂商按原样保留英文：`RCA`、`SCI`、`VMI`（官方三语也没译它们）。

顺带修掉一处会读成"厂商"的误译：`Generic` 出现在**弹药 / 推进器 / 散热器**等通用件上，
它表达的是"这是通用零部件"而不是某家厂商，译名由"通用工业"改为 **"通用组件"**；
并且把那一行前面的标签 `制造商:`（所有部件共用的标签 key）去掉，现在只显示名字。

### 关于 README 里的界面截图

仓库 README 里的截图取自 v1.0 / v1.2 时期，**已不代表当前版本的显示效果**
（这一版之后更是如此：厂商名、百分比、术语都变了）。**请以把 mod 装进游戏后的实际显示为准。**

### 该不该升级

从 v1.2.2 / v1.2.3 升上来的，直接覆盖即可 —— 存档、模组类型、字体都没有变化。
**从 v1.2.1 及更早**升级的，请先看
[v1.2.2 的发版说明](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/releases/tag/v1.2.2)：
那一版修掉了原版 ModLoader 的"禁用系统模组"崩溃，并让新存档不再依赖汉化，
升级要做两步（删旧的 `systemMod.json` + 清一次 `mods\HBS\Cache\`），
以及"用旧版本玩过的存档读不了怎么办"。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

### 已知限制

- 机甲详情面板**最上行**那个大写名字、驾驶员头像下方的**呼号**仍是英文（那两处不走游戏的本地化流程）
- 主菜单右下角的 Season Pass 横幅仍是英文（不经过游戏本地化系统）
- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**

每一条改动的判据（官方 de/fr、key 里的英文原文、处理理由）都逐条记在
`corpus/font-atlas/overrides.jsonl` 与 `tools/merge-final.mjs` 的注释里；
制造商译名的原稿与策略点评留档在 `corpus/manufacturers-src/`。
