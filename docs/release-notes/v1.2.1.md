## v1.2.1 — 随包说明文件修正（译文与 v1.2 完全相同）

这一版**没有任何译文改动**，`strings_zh-CN.csv` 与 v1.2 逐字节相同。
改的只是 `BTHanHua-mod.zip` 里附带的说明文件 —— 它还在讲早就没有的东西：

- ~~「某个词读起来怪怪的（如「眼毛」）→ 字体字表限制」~~
  v1.1 重建字形图集后已经**不存在字表限制**，这条 v1.0 时代的提示留到现在会误导人
- ~~「字体包 font 是微软雅黑的 SDF 图集」~~
  那个字体包 v1.1 起就**已移除并停止分发**；现在的字形来自 **Noto Sans SC**（SIL OFL 1.1）

顺带把版本号统一成**单一来源**：以前 `mod.json` 里写死 `1.0.0`，仓库那份是手工改成 1.2.0 的，
打包时还得手动同步一次；现在两者由同一个常量生成，不会再对不上。

### 该不该升级

**如果你已经装了 v1.2，不升级也不影响游戏** —— 这版改的是随包的说明文字，不是译文。
想保持文档准确就覆盖一次，方法同下。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

### 已知限制

- 机甲详情面板**最上行**那个大写名字仍是英文（同一字符串在下一行已汉化，说明那行不走本地化）
- 主菜单右下角的 Season Pass 横幅仍是英文（不经过游戏本地化系统）
- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**

译文内容与限制详见 [v1.2 的发版说明](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/releases/tag/v1.2)
与 [README](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN#readme)。
