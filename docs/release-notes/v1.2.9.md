查表时用的 key 是**去掉引号**的形态。之前按原文算出的 key 是死的，所以你在游戏里看到的仍是旧机翻。
现在两种形态都写入了，去引号那条（游戏真正用的）已换成精修稿 —— 弓箭手显示为
"大名鼎鼎的「弓箭手」正是「导弹艇」概念的典型代表…"。

### 3. 两处照英文语序硬搬的句子

### 4. COIL 武器名统一为"线圈"

英文原名 **COIL Beam**，COIL = *Contained Overflow Inertia Linkage*；德语把它意译成 **SPULE-Strahl**
（Spule＝线圈）。中文原本四套叫法并存（科尔约射束 / 科尔约-L / 轻型线圈喷射 / 线圈射线），现统一：

| 旧 | 新 |
|---|---|
| 科尔约射束、科尔约-L/M/S | **线圈光束、线圈-L/M/S** |
| 轻型线圈喷射、中型科尔约光束、重型科尔约光束炮 | **轻型/中型/重型线圈光束** |
| "收容超载联动"—科尔约— / "通过连接能量降低潜在不动性"（COIL） | **线圈（COIL）光束武器系统** |
| 研究设施清单里的"科尔约炮 / 科尔约" | **线圈炮 / 线圈** |

### 5. LRM / SRM 表述规范（按你定的规则）

- 有具体型号时：**型号 + 种类**（`LRM-10长程导弹`、`SRM-6短程导弹`）—— 全语料 74 处本来就合规
- 只泛称时：**一律用中文全称** —— 本轮改掉 9 处可见的裸用：长程导弹载具 / 运载车 / 平台 / 发射器 /
  弹药箱、短程导弹弹药箱、长程导弹武器、"装长程导弹的潜行者"、"你妈和长程导弹"、"长程导弹私活"
- 仍在用英文缩写的 15 处属可接受：已带中文注释的（"长程导弹（LRM）火力"）、链接占位符里的武器路径
  （`Weapon_LRM_LRM15`）、以及一个内部状态效果名

### 该不该升级

- 从 **v1.2.8** 升上来：若你只想要字体修复，不必升；想要这批译文，覆盖文本包即可（DLL 与 v1.2.8 相同）。
- 从 **v1.2.1 及更早**升上来：请看
  [v1.2.2 的发版说明](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/releases/tag/v1.2.2)，
  那一版修掉了原版 ModLoader 的"禁用系统模组"崩溃，升级要做两步（删旧 `systemMod.json` + 清一次 `mods\HBS\Cache\`）。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。
