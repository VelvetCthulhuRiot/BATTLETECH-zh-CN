## v1.2 — 机甲名与呼号全面补齐，正文用词统一

这一版的主题是**"同一个东西只有一个叫法"**：机甲名、机甲角色、飞行员呼号与姓名全部补齐并互相统一，
正文里跟这些名字有关的地方也一起对齐。

### 机甲名

- **DLC 机甲的名字以前根本没汉化** —— 原因很实在：它们的定义文件不在游戏磁盘上，而是躺在
  `flashpoint` / `heavymetal` / `urbanwarfare` 三个 asset bundle 里，静态扫描扫不到。
  这次用 UnityPy 把它们抽了出来（**35 个 mechdef + 35 个 chassisdef**），
  于是 Archer（弓箭手）、Javelin（标枪）、Cyclops（独眼巨人）、Assassin（刺客）等全部有了中文名。
- **覆盖机甲库里的三种名字形态**：列表/提示框用的型号名、详情面板下行的变体全名
  （`重甲铁骑 CTF-1X`），以及 52 张机甲肖像图对应的机甲方清单，**不再有漏译的机甲名**。
- **66 个机甲名做了人工精修**，不再逐字直译，例如
  `Cataphract 具装骑兵 → 重甲铁骑`、`Hatchetman 短斧客 → 斧王`、`Quickdraw 迅击 → 闪击`、
  `Vindicator 复仇者 → 捍卫者`、`UrbanMech 城市机甲 → 都市战甲`、`Grasshopper 蚂蚱 → 蚱蜢`。

### 机甲「常备角色」

机甲库提示框里那行 `常备角色: xxx` 来自 `chassisdef` 的 `StockRole` 字段，
也是"把数据里的英文字符串当 key 查 CSV"，缺 key 就显示英文（比如歼灭者原来显示 `Juggernaut`）。

**56 种角色全部人工重译**，不再有机翻痕迹：

```
Brawler                    格斗
Juggernaut                 重装
Missile Boat               导弹平台
Scout / Hunter-Killer      侦察 / 猎杀
Heavy Striker & Disabler   重型突击与致瘫
```

### 正文与名字对齐

- 正文里的机甲名统一到当前译名，共 **85 处**（`报丧女妖 → 女妖`、`快枪 → 闪击`、
  `城市机甲 → 都市战甲` 等）。以前同一台机甲在简介和正文里有两个叫法，会让人以为是两台。
- 中文机甲名**统一加双引号**（`祖传的""海盗旗""`），并清掉语料里混用的另一种引号写法。
  `雷电`/`蜘蛛`/`蝗虫` 这类同时也是普通词的机甲名，只在明确指机甲时才加，避免把
  「如果我没弄错的话，是一只狼獾」这种句子写坏。

### 呼号与姓名

- 飞行员**呼号 35 条 + 姓名 153 条**按人工方案落地，并逐条核过是不是真呼号
  （例如 `heavybrawler` 是机甲角色、`elitebrawler` 是呼号，两者不能混）。
- 名字前面被误加的破折号、空格等脏数据一并清掉（副舰长原来显示成 `—达吕斯`）。

### 字体渲染

- **修掉 `<i>` 斜体压字**：图集材质原先沿用了从微软雅黑 dump 来的 `italicStyle = 35`，
  而 TMP 的 `<i>` 是靠"把位图字形整体切变"实现的假斜体，中文字形本来就占满字框，
  一切变就压到相邻的字（剧情里的「需要」「属于」最明显）。现在设为 **0**：
  `<i>` 标签照旧解析，只是不再变形。

### 译文修正（逐条记录在 `tools/font/overrides.jsonl`，带官方 de/fr 依据）

- `BSC System` 原译「BSC星系」→ **弹道攻城补偿系统**（`system` 被当成天文"星系"了）
- `StatusEffect-BSC-BallisticBoost` 原译「状态效果 **BBS** 弹道提升」→ BSC
  （BBS 是德语缩写，被从官方德语 CSV 照抄了过来）
- 部件属性标签 `bonuses:` 原译「奖励:」→ **效果:**（`reward` 才是任务报酬，仍作"奖励"）
- 副舰长那段对话里的 `""加贺""Kaga(维公主的K-2型""弩炮"")` → 删掉译者自加的括号注解，
  按英文原文重写
- 凯尔猎犬介绍里凭空多出来的中间名 `帕特里克(·马丁·凯尔)` → 删掉
- `FrankenMech` → **拼装机甲**；断裂的句子（`东西.1X型`）一并修好

### 界面截图

README 里的截图全部换成游戏内实拍（10 张）。MOD 管理界面与语言设置界面的截图只放在

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`，然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

> 从 v1.1 升级：直接覆盖即可，不需要改任何设置。

### 已知限制

- 机甲详情面板**最上行**那个大写名字仍是英文 —— 同一个字符串在下一行已经汉化，
  说明那一行游戏没走本地化系统，CSV 覆盖不到
- 主菜单右下角的 Season Pass 横幅仍是英文（不经过游戏本地化系统）
- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**

详见 [README](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN#readme) 与
[字体方案文档](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/blob/main/docs/FONT-ATLAS.md)。
