## v1.2.6 — 遭遇战"天候"标签 + 5 处机甲短简介译文修订

这一版**只改译文**：`BTHanHuaFont.dll` 与 v1.2.5 完全相同，两个 `mod.json` 的行为、
存档相关设置也都没动（`strings_zh-CN.csv` 有 8 条变化）。

### 1. 遭遇战设置里"地图"旁边那个标签

原来译成 **"情绪"**，但下拉里的选项是"雾茫茫的下午 / 雨天 / 日落 / 雾夜 / 多雾的日间…"——
它其实是**天候 + 时段的灯光氛围预设**（英文原文就是 HBS 引擎里的行话 `Mood`）。
官方德语/法语也按字面直译成了 `Gemütslage` / `Humeur`（同样是"情绪"，也同样是错的），
所以这里没有跟官方，按实际内容改成了 **"天候"**（`mood` / `mood:` / `moods` 三条统一）。

### 2. 四处机甲短简介

| 机甲 | 旧 | 现在 |
|---|---|---|
| **都市战甲** UM-R60 | 不要被粗短的"**市区**"给欺骗了 | 不要被粗短的"**都市战甲**"给欺骗了 |
| **驼背** HBK-4G | 久经考验的**重锤机** ／ 一般都会在它的**足部**安装重甲 | 久经考验的**重装机甲** ／ **而且通常还会加装重甲** |
| **黑豹** PNT-9R | **甚至为了产生良好的效果**，它们还被用于拳击比赛 | **甚至为了物尽其用**，它们还被用于拳击比赛 |
| **纵火犯** FS9-H | 喷火器攻击能**关闭**任何机甲，让它敞开迎接来自你其它部队的惩罚 | 喷火器攻击能**让任何机甲过热关机**，让它们**毫无防御地承受来袭的攻击** |

其中两处是真正的误译，顺手一并修掉：

- `Urbie` 是 UrbanMech 的昵称，旧译按 `urban`（市区）直译了 → 改用机甲既定译名"都市战甲"；
- `It tends to mount heavy armor **to boot**` 里的 `to boot`（此外/而且）被当成了"靴子"，
  译成了"在它的**足部**安装重甲" → 改为"而且通常还会加装重甲"。

### 3. 顺带：机甲提示框顶部的 `CLASS:`

机甲详情的标题行原来是 `30吨 (CLASS: 轻型)` —— 标签来自模板 key `(class:{0})`，
其值是 `( Class: {0} )`，当初只译了 `{0}` 没译标签。现在统一为 **`( 类别: 轻型 )`**，
与已有的四条 `class:light` / `medium` / `heavy` / `assault`（"类别: 轻型"…）一致。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

### 已知限制（未变）

- 机甲详情面板**最上行**那个大写名字、驾驶员头像下方的**呼号**仍是英文（不走游戏的本地化流程）

- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**
- README 里的界面截图取自更早的版本，**以装好 mod 后的实际显示为准**
