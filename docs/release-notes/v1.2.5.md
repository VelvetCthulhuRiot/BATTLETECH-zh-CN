## v1.2.5 — 修掉设置里"质量"档位显示成"中型"

这一版**只有字体模组那一半的 DLL 变了**：`strings_zh-CN.csv`（21,875 条译文）与 v1.2.4
**逐字节相同**，两个 `mod.json` 的行为、存档相关设置也都没动。

### 问题

设置 → 视频 → **质量** 的下拉里，中间那档显示成了 **"中型"**（应为"中"）：

```
低 / 中型 / 高 / 超高 / 自定义     ← 修复前
低 / 中   / 高 / 超高 / 自定义     ← 现在
```

### 原因：同一条 key 被两个界面共用

游戏里 `Medium` 这个词出现在**两个互不相关**的地方，而它们共用同一条本地化 key `medium`：

| 场合 | 来源 | 同族词 |
|---|---|---|
| **机甲吨位级别** | 机甲定义里的 `"weightClass": "MEDIUM"` | 轻型 / 中型 / 重型 / 突击 |
| **画面质量档位** | Unity 的画质名 `Medium` | 低 / 高 / 超高 / 自定义 |

英语和德语"一个词两处都通"（`Medium` / `Mittel`），所以官方本地化没有冲突；
中文不行 —— "中"和"中型"要分开，而 CSV 里一条 key 只能有一个值。
上一版把这条 key 改成"中"之后，**机甲的"中型"也跟着变成了"中"**（用户实测确认）。

### 解决：译文按机甲优先，画质那处在运行期按界面改写

- **CSV 保持"中型"** —— 出现频率高得多的机甲库 / 机甲详情 / 商店天然正确；
- **`BTHanHuaFont` 只在"设置界面可见"时**，把屏幕上的"中型"改写成"中"。
  判据是几段**只可能出现在设置界面**的探针文本（设置菜单 / 伽玛值 / 按键绑定 /
  启用不支持的分辨率）；游戏各界面是互斥的全屏界面，所以机甲库绝无被误改的可能。
  挂载点：字体同步 `Sync`、标签刷新 `PostfixLoadFontAsset`，再加 1 秒一轮的兜底扫描
  （游戏重新本地化或下拉项复用把文字写回"中型"时会再改一次）。

改的是**显示层**：不改游戏数据、不改 CSV，所以没有任何存档或模组状态相关的影响。

### 该不该升级

- 从 **v1.2.4** 升上来：覆盖两个文件夹即可（其实是 `BTHanHuaFont` 里的 DLL 变了）。
- 从 **v1.2.1 及更早**升上来：请先看
  [v1.2.2 的发版说明](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/releases/tag/v1.2.2)
  —— 那一版修掉了原版 ModLoader 的"禁用系统模组"崩溃，升级要做两步
  （删旧的 `systemMod.json` + 清一次 `mods\HBS\Cache\`），并说明了旧存档的处理。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

### 已知限制（未变）

- 机甲详情面板**最上行**那个大写名字、驾驶员头像下方的**呼号**仍是英文（不走游戏的本地化流程）
- 主菜单右下角的 Season Pass 横幅仍是英文
- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**
- README 里的界面截图取自更早的版本，**以装好 mod 后的实际显示为准**

> 如果你在设置界面里看到"质量"仍显示"中型"，把
> `Documents\My Games\BattleTech\mods\BTHanHuaFont\BTHanHuaFont.log` 发到 issue：
> 生效时里面会有一行 `MEDIUM '<标签名>' 设置界面: 中型 -> 中`。
