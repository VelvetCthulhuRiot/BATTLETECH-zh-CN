## v1.2.2 — 修掉原版 ModLoader 的"禁用系统模组"崩溃 + 两轮译文修订（206 条）

> 🔴 **升级前请先读「存档」一节**：本版改变了模组对存档的影响方式，
> **用 v1.2.1 及更早版本玩过的存档在升级后会读不了**（有救法，见下）。

### 1. 修复：游戏内禁用模组会永久损坏模组状态

这是**游戏自带 ModLoader 的 bug**，与汉化无关，但本汉化的字体模组以前正好是
**系统模组（System Mod）**，所以踩得到。

**症状**（每次启动都复现）：保存游戏永远卡在「正在保存中」、模组界面列表填不出来、存档校验异常。

**原因**（反编译 `Assembly-CSharp.dll` 实证）：`ModLoader.InitSystemModsLoop` 里"该模组被禁用"
那个分支写错了表 —— 它去动 `loadedGameModStatus`，而系统模组的条目在
`loadedSystemModStatus` 里，于是 `KeyNotFoundException`；异常被 catch 后
`FailToLoadModDef` / `UpdateModStatus` 把失败的 def 注入两个状态文件，此后
`GetCombinedModStatus()` 用 `Dictionary.Add` 合并两张表就撞重复键。
同位置的 `InitGameModsLoop` 用的是自己那张表，所以**禁用游戏模组不会崩，禁用系统模组必崩**。

**本版的对策**：`BTHanHuaFont` 的 `systemMod.json` → **`mod.json`**（普通游戏模组）+ 空 `Manifest`。
DLL 不是系统模组的专利 —— 官方 Mod Support PDF §2.3.4 写明 `DLL` 字段**对游戏模组是可选的**，
只有系统模组才必需。已实测：改成游戏模组后 DLL 照常加载（9 个 Harmony 挂钩、字形图集 CRC OK、
运行时漏译计数 0），且 `system_mod_status.json` 变成 `{}`，那条崩溃路径再也走不到。

**顺带**：在 MODS 界面里勾选/取消勾选本汉化的两个模组现在是安全的。
但如果你还装了**别的系统模组**，仍然不要在游戏里禁用它们 —— 要关就退出游戏再移出文件夹。

### 2. 🔴 存档：装了本版之后新存的档不再依赖汉化

两个模组都标了 `"IsSaveAffecting": false`。含义与代价：

| 设置 | 新存的档 | 已有的档 |
|---|---|---|
| **本版（`false`）** | 不再依赖汉化 —— 卸载汉化后照样能读 ✓ | **v1.2.1 及更早版本玩过的档会显示「未安装/激活所需的模组」** ✗ |
| v1.2.1 及更早（默认 `true`） | 依赖汉化 —— 卸载后读不了（官方 PDF §1.5.2 的原版设计） | 装汉化前后都能读 ✓ |

**想读回旧档**：把两个 `mod.json` 里的 `"IsSaveAffecting": false` 这一行**删掉**，重启游戏即可
（这个判定是**每次读档时现算**的，不写进存档文件，来回切换不会损坏任何东西）。
代价是新档又会重新依赖汉化 —— 两个方向只能选一边。

我们选 `false` 是因为这是纯文本/字体汉化，不改变存档数据，本就不该让存档反过来依赖它。

### 3. 译文修订（`strings_zh-CN.csv`，共 206 条）

来自玩家逐条截图反馈：

- **漏译/坏值**：对话里的 `马卡姆's Marauders`、莫名其妙的 `?H`（原文是 `He, uh... well.`）、
  家族简介里的 `ibex`（→ 北山羊）、升级界面的 `MechTech 点数`（→ 技师点数）
- **术语统一**：`血票`/`血牌` → **血幅**；`肉搏` → **近战**（武器栏那一行 → **近战攻击**）；
  战斗资源 Resolve 由「决心」改为 **战斗决心**（原来与公司层面的 Morale「士气」撞名）；
  `机甲勇士` → 机甲战士
- **机甲库那一屏**：Mech Bay = **机甲库**、Mech Cubicle = **机甲隔舱**、Repair Scaffolding = **维修脚手架**
  三个词彻底分清（原来 cubicle 和 bay 都被译成"维修脚手架"）
- **阿尔戈号升级界面**：大图标与详情里的分类名不一致 —— 栖息胶囊→**居住舱**、
  训练→**训练模块**、修复改造→**维修与改装**
- **显示错乱**：14 处富文本标签写成 `<color = #85DBF6FF>`（等号两侧带空格，游戏解析不了、
  会把标签当文字显示出来）统一修正；机甲维修界面吨位显示「12吨**S**剩余」里的 `S`
  是英文复数后缀占位符，中文已去掉
- 教程选项「温暖，稳定性和修饰符」→「**热量、稳定性与修正因子**」（`Heat` 被译成了"温暖"）

每一处改动的判据（官方 de/fr、key 里的英文原文、处理理由）都逐条记在
`corpus/font-atlas/overrides.jsonl` 与 `tools/merge-final.mjs` 的注释里。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

**从 v1.2.1 及更早版本升级，请一定做完这三步**：

1. 删掉 `mods\BTHanHuaFont\systemMod.json`（如果还在）——
   同一个文件夹里同时有 `systemMod.json` 和 `mod.json` 会让同一个模组名进两张表，
   正好触发上面那个重复键崩溃
2. 删掉这几个缓存文件让游戏重建（**保留** `HBS\Database\MetadataDatabase.db`）：
   `mods\HBS\Cache\mod_status.json`、`system_mod_status.json`、`merge_cache.json`、
   `type_cache.json`、`mods\load_order.json`
3. 若你有 v1.2.1 及更早玩过的存档，按上面「存档」一节决定要不要删掉
   `"IsSaveAffecting": false` 那一行

### 已知限制

- 机甲详情面板**最上行**那个大写名字、驾驶员头像下方的**呼号**仍是英文
  （同一字符串在其它位置已汉化，说明那两处不走游戏的本地化流程，需从字体模组侧挂 UI 补丁）
- 主菜单右下角的 Season Pass 横幅仍是英文（不经过游戏本地化系统）
- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**

译文与其它限制详见 [README](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN#readme)。
