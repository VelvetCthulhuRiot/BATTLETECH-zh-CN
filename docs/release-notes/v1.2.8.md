## v1.2.8 — 修掉「切到俄语后满屏方块」

### 问题

在 **设置 → 语言** 里切到**俄语**后，整个界面变成方块（□）；
而其它官方语言（English / Deutsch / Francais）正常。玩家报告并确认是汉化 MOD 引起的。

同一个原因还导致：语言下拉列表里 `русский` 那一项**本身就是方块**。

### 原因

字形图集里有中日韩汉字、拉丁字母、以及带音标的拉丁字母（`é ü ß ç ñ` …），
但**没有任何西里尔字母**（也没有希腊字母）—— 所以俄语文本一旦落到我们图集上就必然是方块。

而它确实会落到我们图集上，因为字体切换逻辑里有一段**无条件还原**：

```
换字体时把"原来的字体"记下来, 文字不再是中文时还原回去:
    t.font = s_origFont[id];        // ← 无条件
```

"原来的字体"是**中文界面时期**记下的。中文没有官方字体，游戏用的是拉丁字体
（`UnitedSans*` / `ProximaNova*`，**不含西里尔**）。切到俄语后游戏本会把字体换成
俄语专用的（日志里见过 `Proxima Nova Semibold SDF RU`），但这段还原又把它盖回了
拉丁字体 → 满屏方块。

另外还有一类文本实例当初**没被登记**过（或登记被清掉了），于是一直挂着我们的图集 ——
所以症状是"绝大多数"而不只是零星几个。

### 修法

只在**「记下的原字体确实能渲染当前文本」**时才还原；盖不住就在游戏现役字体里找一个
盖得住的用（俄语那套 `… SDF RU` 会被选中）：

```
if (Covers(o, txt))         t.font = o;                   // 原字体盖得住 -> 照旧还原
else if (!Covers(target,…)) t.font = FindCoveringFont();   // 都盖不住 -> 用游戏自带语言字体
```

同时把还原条件放宽为「只要当前用的是我们的图集就处理」，不再要求这个文本实例被登记过。

**没有往图集里塞西里尔字母** —— 那样虽然也能出字，但用的是我们的中文字形；
现在直接让游戏用它自己的俄语字体，字形与字重都更正确。这个机制对各种语言都成立，
以后若有人做别的语言包也不会再撞上。

### 影响范围

- **只有 `BTHanHuaFont.dll` 变了**（`D6E6F376…`）。`strings_zh-CN.csv` 与 v1.2.7 逐字节相同。
- 中文界面不受影响（已回归确认）；德语 / 法语等原本正常，因为它们的重音字母本就在图集里。
- 顺带修好了语言下拉列表里 `русский` 显示成方块的问题。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

> 从 v1.2.2 及以后版本升级：直接覆盖即可。更早的版本见
> [v1.2.2 的发版说明](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/releases/tag/v1.2.2)
> （那一版修掉了原版 ModLoader 的"禁用系统模组"崩溃，升级要做两步）。

### 已知限制（未变）

- 机甲详情面板**最上行**那个大写名字、驾驶员头像下方的**呼号**仍是英文（不走游戏的本地化流程）
- 主菜单右下角的 Season Pass 横幅仍是英文
- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**
- README 里的界面截图取自更早版本，**以装好 mod 后的实际显示为准**

> 机甲简介、厂商名与术语的权威来源分别是仓库外的 `corpus/mech-desc-zh.tsv`、
> `corpus/manufacturers-zh.tsv`（随项目语料保存），生成器为 `tools/gen-chassis-desc.mjs` 与
> `tools/gen-manufacturer-keys.mjs`；逐条处理理由记在 `corpus/font-atlas/overrides.jsonl` 与
> `tools/merge-final.mjs` 的注释里。
