## v1.2.3 — 随包说明与 README 的措辞修正（译文与 v1.2.2 完全相同）

这一版**没有任何译文或功能改动**：`strings_zh-CN.csv`、两个 `mod.json` 的行为
（普通游戏模组 + `IsSaveAffecting: false`）都与 v1.2.2 一致，`BTHanHuaFont.dll` 与字形图集也没动。
改的只是**说明文字**：

- 原来的标题写成「⚠️ 不要在游戏内用『取消勾选』来关汉化」，容易被读成"勾选开关很危险"。
  现在直接说明：**v1.2.2 起，在 MODS 界面勾选 / 取消勾选都是安全的，也不会锁住存档** ——
  两个模组都是普通游戏模组，且标记为不影响存档，所以装了本版之后新存的档不依赖汉化。
- 关掉 / 卸载汉化的正确做法写在显眼处：临时关闭就在 MODS 界面取消勾选；彻底卸载就退出游戏后
  删掉两个文件夹。
- v1.2.1 及更早版本的那个原版 ModLoader 缺陷（在游戏内禁用**系统模组**会写坏模组状态）
  降级成**小字历史说明**（README 里折叠在「历史」里），只保留"遇到了怎么恢复"这一句。
- 其余保留：从旧版升级要先删掉 `systemMod.json` 并清一次 `mods\HBS\Cache\`。

### 该不该升级

**已经从 v1.2.2 升上来的，不升级也不影响游戏** —— 这版只改了说明文字。
想保持文档一致就覆盖一次，方法同下。

> 从 **v1.2.1 及更早**版本升级的话，请务必看
> [v1.2.2 的发版说明](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/releases/tag/v1.2.2)：
> 那一版修掉了原版 ModLoader 的"禁用系统模组"崩溃，并让新存档不再依赖汉化；
> 升级步骤（删旧 `systemMod.json` + 清缓存）和"旧存档读不了怎么办"都写在那里。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

### 已知限制

- 机甲详情面板**最上行**那个大写名字、驾驶员头像下方的**呼号**仍是英文（那两处不走游戏的本地化流程）
- 主菜单右下角的 Season Pass 横幅仍是英文（不经过游戏本地化系统）
- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**
