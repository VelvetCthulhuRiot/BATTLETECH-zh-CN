## v1.3.0 — 修掉"进机库/商店卡顿"（字体注入的性能开销）

这一版**只改 `BTHanHuaFont.dll`**：`strings_zh-CN.csv` 与 v1.2.9 逐字节相同，译文没有任何变化。

### 症状

开启汉化后，**进入机库、商店这类文字密集的界面会明显卡顿**（有的玩家描述为"进机库非常卡"）。
关掉 `BTHanHuaFont`（中文会变方块）后卡顿消失 —— 说明问题出在字体注入这一侧，而不是译文数据。

### 原因（实测定位，不是猜测）

给测试版加了逐秒的运行期计数后，从日志里读出来的事实：

| 指标 | 修复前 |
|---|---|
| `Sync`（每次 UI 文本刷新都会走的钩子）调用量 | 一小时约 **3.8 万次**，进入界面时峰值 **6700 次 / 5 秒** |
| 单次调用耗时 | 走"完整判定"时 **2.5 ms**（峰值窗口累计 **4065 ms**） |
| 换字体本身（`SetFont` + TMP 重建） | **4.3 ms / 819 次** —— 根本不是瓶颈 |

也就是说：真正贵的是**每次文本刷新都重新做"这段文字该不该换字体"的判定** —— 逐字查 TMP 字形表
（`HasCharacter`），必要时还要用 `Resources.FindObjectsOfTypeAll` 把游戏里所有字体资产扫一遍。
机库/商店会反复刷新成百上千个文本对象，于是这点开销被放大了上万次。

### 修法

1. **热路径只留一次属性比较**：文本已经在用我们的字形图集（`t.font == target`）→ 直接返回。
   连文本内容都不读。实测这条路径 **0.9 µs/次**。
2. **完整判定只做一次**：文本还没换过字体时，才做"是否中文 / 原字体能不能渲染 / 要不要换"的判定，
   换完字体之后就走第 1 条。
3. **"切到别的官方语言"的还原逻辑挪到 2 秒一次的全场景巡检**：原来它也跟着每次刷新跑，
   现在只在低频巡检里处理，最多 2 秒内恢复（v1.2.8 的跨语言字体修复仍然有效）。
4. 另外：`HasCharacter` 结果按（字体,字符）缓存、`SetFont` 的反射结果按类型缓存、
   两个每秒一次的全场景扫描合并并降到 2 秒一次。

### 效果（同一台机器、同一存档实测）

| 指标 | 修复前 | v1.3.0 |
|---|---|---|
| `Sync` 总 CPU 时间 | **17,676 ms** | **52 ms**（约 1/340） |
| 调用次数 | 37,918 | 60,072（调用更多，但几乎不耗时） |
| 单次平均 | 0.47 ms | **0.9 µs** |
| `hitch>100ms` 帧数 | 37 | 21 |

剩下的 1~2 秒长帧都发生在"加载资源"的时刻（日志里同一窗口的 `sync_ms` 只有 0.2 ms），
是游戏自身的加载行为，与汉化无关。

### 附：新增的诊断开关（普通玩家不用管）

在 `mods\BTHanHuaFont\` 下放一个空文件 `PERF_ON`，日志（`BTHanHuaFont.log`）会每秒写一行
`PERF … frames / max / hitch / sync / swap / scan / texts`。
以后如果有人报告卡顿，让他放上这个文件跑一次、把日志发来，就能直接看到是 CPU 还是 GPU 侧的问题。
不放这个文件时**零开销**。

### 该不该升级

- 从 **v1.2.x** 升上来：**强烈建议**，这一版解决的就是卡顿。
- 从 **v1.2.1 及更早**升上来：请看
  [v1.2.2 的发版说明](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/releases/tag/v1.2.2)，
  那一版修掉了原版 ModLoader 的"禁用系统模组"崩溃，升级要做两步（删旧 `systemMod.json` + 清一次 `mods\HBS\Cache\`）。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

### 已知限制（未变）

- 机甲详情面板**最上行**那个大写名字、驾驶员头像下方的**呼号**仍是英文（不走游戏的本地化流程）
- 主菜单右下角的 Season Pass 横幅仍是英文
- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**
- README 里的界面截图取自更早版本，**以装好 mod 后的实际显示为准**
