## v1.2.7 — 机甲简介全面精修 + 8 家厂商补译 + 几处术语与一致性修复

这一版**只改译文**：`BTHanHuaFont.dll` 与 v1.2.5/v1.2.6 完全相同，两个 `mod.json` 的行为与
存档相关设置也都没动（`strings_zh-CN.csv` 有 **122 条改动 + 17 条新增 key**）。

### 1. 机甲详细描述（提示框里那段简介）全面精修 —— 这是本版的主体

游戏里**全部 124 段机甲简介**都由使用者逐条精修过一遍，覆盖：

- **基础游戏 86 个 chassisdef**（各型号机甲，含同一机甲的改型）；
- **DLC 机甲 32 条**（独眼巨人、蟹、斧王、标枪、渡鸦、步枪手、火神、凤凰、跳蚤、弓箭手、
  刺客、牛鲨、歼灭者、巨钢爪、重甲铁骑 —— 这些定义不在游戏数据目录里，而在
  `flashpoint` / `heavymetal` / `urbanwarfare` 三个 asset bundle 中）；
- **3 条"特殊型号"**（百夫长 CN9-AS、黑豹 PNT-9R、影鹰 SHD-2D —— 简介只写在 mechdef 上，
  与同型号普通机体的文本不同）。

其中 **9 条官方从未本地化**（弓箭手 ARC-2R、火神 VL-5T 等），本版作为**额外 key**补进汉化文件，
游戏里不再显示英文。含富文本标签或省略号的几条，同时写入了多种 key 形态，确保游戏按哪种
规范化形态查表都能命中。

之前有几家部件/设备厂商因为定义文件里带**尾随逗号**（Unity 导出的 JSON）没被扫到，界面上一律显示
英文。现已补齐：

|---|---|---|
| Stormvanger | 斯托姆万格 | 高级指挥模块（独眼巨人 HQ） |
| StarCorp | 星团工业 | 优化后的电容 |
| Garret | 加雷特 | 目标捕获装备 / TAG、测距仪套件 |
| Livingston Ceramics | 利文斯顿陶瓷 | 瞄准挡板（跳蚤） |
| Fusigon / Herakleion / Hovertec | 弗西贡 / 赫拉克利翁 / 霍弗泰克 | 重金属 DLC 的各类武器 |
| Shengli Arms | 胜利军械 | LB 20-X 系列 |

### 3. 设备名与描述不一致

「近战装备」（CQC Suite）的描述里原本写"近战模块"，与设备名对不上（官方德译也写作
Nahkampfmodul），且句中有个重复的逗号。已统一到设备名：

> 近战装备为火神的辅助武器提供了射程加成，让它能从更远的距离发动攻击。该装备还能很好地防御
> 敌方的报复性近战攻击。

### 4. 「独眼巨人」作战电脑

原文 `…effectively command dozens of units` / 德语 `…Befehl über Dutzende von Einheiten`，
旧译"指挥几打单位"是把 dozens 直译了。现改为"可以有效地指挥**数十个单位**"，并修掉句末的半角句号。

### 5. `myomer` 术语统一（肌动器）

全语料原本有 6 处音译"**麦约摩尔**"，而精修后的渡鸦 RVN-3X 简介用的是"**肌动器**"。已全部统一为
**肌动器**，并把两个原型名称统一为「原型三重肌动器」「原型三重强度肌动器」。

顺便澄清一个常见疑问：**Triple Strength Myomer 在游戏里不是可购买的部件** ——
它是 RVN-3X 那套实验性肌动器的状态/能力名，游戏数据里没有任何以此为名的装备定义，
所以在市场上刷不出来。

### 6. 影鹰 SHD-2H 简介

"「影鹰」2H是一个「万事通」的完美案例" → 用词改为 **「万金油」**。

### 该不该升级

- 从 **v1.2.6** 升上来：只覆盖文本包即可（`BTHanHua` 文件夹；DLL 没变，直接沿用它也行）。
- 从 **v1.2.1 及更早**升上来：请先看
  [v1.2.2 的发版说明](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/releases/tag/v1.2.2)，
  那一版修掉了原版 ModLoader 的"禁用系统模组"崩溃，升级要做两步
  （删旧 `systemMod.json` + 清一次 `mods\HBS\Cache\`）。

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`（覆盖旧的），然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

### 已知限制（未变）

- 机甲详情面板**最上行**那个大写名字、驾驶员头像下方的**呼号**仍是英文（不走游戏的本地化流程）
- 主菜单右下角的 Season Pass 横幅仍是英文
- CJK 扩展 B 及以后的字符无法渲染（TMP 1.2 的字符索引链限制）
- 仅支持游戏 **1.9.1 (build 686R)**
- README 里的界面截图取自更早版本，**以装好 mod 后的实际显示为准**

> 机甲简介、厂商名与术语的权威来源分别是仓库外的 `corpus/mech-desc-zh.tsv`、
> `corpus/manufacturers-zh.tsv`（随项目语料保存），生成器为 `tools/gen-chassis-desc.mjs` 与
> `tools/gen-manufacturer-keys.mjs`；逐条处理理由记在 `corpus/font-atlas/overrides.jsonl` 与
> `tools/merge-final.mjs` 的注释里。
