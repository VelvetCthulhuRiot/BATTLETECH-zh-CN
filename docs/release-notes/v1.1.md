## v1.1 — 用 Noto Sans SC 重建字形图集，彻底解决缺字

### 字形

- **8,352 个字形**，覆盖《通用规范汉字表》一级/二级/三级**全部 BMP 汉字**（7,909 字）
- 由 **Noto Sans SC**（Google 与 Adobe 联合开发，与思源黑体同源，**SIL OFL 1.1**）离线生成，可自由再分发
- 图集为 8192×8192 Alpha8、75px 字形；渲染质量与行距和 v1.0 **逐像素一致**
- **移除了 v1.0 随包的微软雅黑图集**（再分发授权不明确），授权隐患彻底消除

### 译文

- **回滚全部 816 条字形替换规则**，恢复自然措辞：`眉毛`（原来被迫写成「眼毛」）、`鸣谢`、`渡鸦`、`翡翠曙光` 等等
- 补回官方有、旧版因缺 `¢` 字形而删掉的**星币符号**（75 个键），例如 `现金奖励： 1，000，000` → `现金奖励： ¢1,000,000`
- 修正若干确认的译文错误：`疤痕`（原「创伤」）、`妆容`（原「美容」）、`中型`（原「中等」）、`显示标准`（原「显示库存」）、`枪炮`（属性栏原来只显示「枪」）等，逐条记录在 `tools/font/overrides.jsonl`，带官方 de/fr 依据

### 安装 / 升级

下载 `BTHanHua-mod.zip`，把 `mods` 里的**两个文件夹**复制到
`C:\Users\<你>\Documents\My Games\BattleTech\mods\`，然后
**MODS → 勾选「模组启用」→ 保存 → 完全重启游戏 → 设置 → LANGUAGE → 中文**。

> 从 v1.0 升级：直接覆盖即可。旧包里的 `BTHanHuaFont\font` 文件可以删掉（v1.1 不再使用）。

### 已知限制

- **CJK 扩展 B 及以后无法渲染**（非 BMP 字符，TMP 1.2 的字符索引链限制），规范字表里的 196 个此类字符已排除
- 主菜单右下角的 Season Pass 横幅仍是英文（不经过游戏本地化系统）
- 仅支持游戏 **1.9.1 (build 686R)**

详见 [README](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN#readme) 与
[字体方案文档](https://github.com/VelvetCthulhuRiot/BATTLETECH-zh-CN/blob/main/docs/FONT-ATLAS.md)。
